# Safety Solutions

V1 gratuita em GitHub Pages + Supabase.

## Configuração final

O código público usa `config.js` com placeholders. Para ativar autenticação e banco:

1. Abra `config.js` no GitHub.
2. Substitua `COLE_AQUI_SUA_URL_DO_SUPABASE` pela Project URL.
3. Substitua `COLE_AQUI_SUA_CHAVE_PUBLICAVEL` pela chave **publishable** do projeto.
4. Nunca coloque Secret Key ou service_role no site.
